## 为什么自己搭一个博客

社交平台适合碎片化的表达，但不适合沉淀。一个属于自己的站点有三个好处：

1. **内容归自己**——数据就是仓库里的 Markdown 文件，随时可以迁移。
2. **可以慢慢改**——今天加个读书笔记，明天换个主题，都是改代码的事。
3. **没有算法**——谁来看、看多久，不需要向任何推荐系统交代。

## 这个站是怎么工作的

```bash
npm run build   # 把 src/content/ 下的 Markdown 编译成静态 HTML
npm run dev     # 本地开发服务器
```

写一篇文章只需要三步：

- 在 `src/content/blog/` 新建一个 `.md` 文件；
- 填上 `title`、`description`、`pubDate` 这几个 frontmatter 字段；
- `git push`，GitHub Actions 会自动构建并部署。
